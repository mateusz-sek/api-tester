# REST API Automated Tests (Python + Requests + Pytest)

Zestaw automatycznych testów weryfikujących poprawność działania publicznego REST API (statusy HTTP, struktura JSON oraz obsługa błędnych zapytań).

## Uruchomienie
1. Zainstaluj wymagane biblioteki:
   `pip install pytest requests`
2. Uruchom testy:
   `pytest`
